# Intune / Endpoint Configuration Runbook
Tenant-side steps that should be performed in Microsoft Intune:
1. Enroll a test Windows 11 device under Corporate Users.
2. Create a Windows configuration profile.
3. Create a compliance policy requiring firewall/secure settings.
4. Deploy a test application.
5. Configure Conditional Access requiring compliant devices.
6. Verify device compliance and policy application.

Capture screenshots: Intune device, configuration profile, compliance, app deployment, Conditional Access.
